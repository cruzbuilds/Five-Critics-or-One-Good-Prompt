### Blocking

**`README.md:27`, `.env.example:2`, `src/lib/auth.ts:9`**
- [docs-reviewer, security-reviewer] The README says to "keep the defaults" for `JWT_SECRET`, and the `.env.example` placeholder passes the `< 16` length check in `getSecretKey()`. A deployment that copies the example file signs sessions with a publicly known key, so anyone can forge a session cookie. The README also never says what `JWT_SECRET` is, that it is required, or what fails without it. A missing or short secret throws, so login and register return 500 and `src/proxy.ts` silently redirects `/ideas` to `/login`. Add an env-var section with a generation command such as `openssl rand -base64 32`. Reject the placeholder in code. Remove "or keep the defaults". Docs-reviewer rated this Blocking and security-reviewer rated it Should fix; I kept the higher severity.
