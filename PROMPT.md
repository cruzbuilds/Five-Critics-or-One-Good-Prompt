# The build prompt

Paste this into the fresh session. Nothing else. No preamble.

---

Build me a web app where I can log ideas I have as a builder, score each one from 1 to 5 on differentiation, evidence, cost and reversibility, and see them ranked by total score. When I finish or abandon an idea I want to record what actually happened and score it again in hindsight, so I can see over time where my predictions were off. It needs accounts so my ideas are private, and I want to be able to share a single idea with someone by link without them signing up. Use TypeScript for everything, a real API and a real database, not a toy. Make it look decent.

---

## While it runs

Answer, never steer.

- Question the paragraph covers: short factual answer. Record it verbatim.
- Question it does not cover: "your call."
- "Should this be secure / tested / documented?": "your call." Write the question down word for word.
- Choice you think is wrong: say nothing, write down that you noticed.
- Broken output: leave it broken.
- It says it is done: it is done.

Never say: keep going, now clean that up, add tests, are you sure, what about auth, one more thing.
